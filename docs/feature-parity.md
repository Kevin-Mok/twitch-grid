# Viewington feature parity

This matrix separates reference evidence from rebuild delivery. Read the [research report](research.md) for reproduction steps, exact REA IDs, hashes and limits. Delivery verification is completed by the implementation pass; a visible reference control does not prove its runtime behavior or rebuild success.

**Reference status:** observed = exercised/rendered in the reference browser; inferred = supported by delivered source/package inspection; unverified = not established. All desktop runtime behavior remains unverified even when a static feature is inferred. **Delivery status:** implemented, partial, blocked, or not applicable. Rows marked partial pending verification are targets awaiting implementation evidence, not completion claims.
