# Reference tooling contract mismatches

This report records research-tool failures while inspecting Viewington, their scope, and the corrected workflows. It does not describe failures of the rebuilt application.

- Symptom: `bsdtar -tf` could not read the officially downloaded NSIS installer (`Unrecognized archive format`). `file` identified the package as a PE32 Nullsoft self-extracting archive; a format-capable extractor is needed.
- Symptom: the first `chrome-devtools-axi snapshot` on the dedicated CDP browser reported `No page is currently selected`; the browser bridge requires explicit target selection before capture.
- Symptom: the initial REA target-list command returned `invalid_request` because a JSON-array string was passed to the CLI array flag. Passing a single origin as an ordinary argument succeeded.
- Symptom: an ad hoc JSON summary used list slicing on the `scripts` object and raised `KeyError`. The REA capture itself succeeded; inspect the returned object shape before extracting fields.
- Symptom: `Settings` click timed out because the sidebar is initially translated off-screen despite its accessibility nodes being present. Open the visible sidebar toggle before interacting with hidden controls.
- Symptom: REA `analyze-web-bundle --fetch-source-maps` on the complete Next.js reference exhausted the default approximately 4GiB Node heap and exited134. The initial passive script capture succeeded and remains available; no partial bundle result counts as evidence.
- Symptom: `npm exec --package=7zip-bin -- node -p require.resolve(...)` installed the package but could not resolve it from the working directory. npm exec adjusts executable search paths, not the working directory's Node module resolution; the installed absolute binary path was then discovered directly.
- Symptom: asynchronously changing Twitch accessibility trees made saved AXI references stale, and an unguarded follow-up Enter reached the previously focused profile input. No added channels were claimed from that attempt. Subsequent sequences used `set -e`, explicit focus, fresh snapshots, or stable observed DOM button labels.
- Symptom: initial ASAR extraction reported missing unpacked companion `resources/icon.png`. Static installer extraction had selected only app.asar and metadata. Extracting the companion resource from the same verified installer next to the archive enabled the successful REA retry.
- Symptom: the `lz-string` package's CLI interpreted `--help` as an input filename and returned ENOENT. Its library API was used through the explicitly located package instead; compression fixtures then round-tripped in the live reference UI.
- Symptom: one ad hoc dropdown-inspection expression contained an extra closing bracket and was rejected before execution. It changed no target state; the corrected expression uses `Array.from`.
- Additional tool boundary: AXI `fill` populated the reference settings textarea but did not enable its React import button until a real keyboard edit was sent. Fresh refs plus End/Space/Backspace enabled Import, which then displayed `Settings imported successfully!`; this is recorded as tooling behavior rather than a product defect.
- Impact: these initial probes produced no feature evidence. No target installer was executed and no existing user browser session was accessed.
- Knowledge lookup: canonical query `browser No page selected archive Unrecognized archive format` returned media-selection, Playwright sandbox and optional-path findings, none matching these contract mistakes. The actual tool help and saved errors are the applicable evidence.
- Current status: usable evidence delivered. Browser selection, origin arguments, fresh references, library resolution, ASAR companions and bounded analysis all have verified workarounds. The full-site bundle parse remains uncompleted after its heap failure; the bounded app-specific pass is explicitly partial. NSIS extraction succeeded through the temporary7zip binary rather than bsdtar.
- Next steps: keep the documented full-site/source-map/Windows runtime limitations. No further resource-heavy retry is needed for the delivered browser implementation.
- Heap knowledge lookup: `Node heap out of memory bundle analysis` returned unrelated console and process-accounting findings; no matching REA remedy was found. The narrower analyzer's documented source/heap/time bounds guide the next probe.
